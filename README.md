# Mama S. Ceesay Portfolio

A personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## Files

- `index.html` contains the portfolio content.
- `styles.css` contains the responsive layout and visual styles.
- `script.js` contains the interactive behavior.
- `images/` contains the images used by the site.

The `deliverables/` folder contains presentation files and is not included in this repository.

## GitHub Pages

The site is published from the `main` branch at the repository root.
