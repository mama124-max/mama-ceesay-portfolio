# Mama S. Ceesay — Portfolio

A personal portfolio built with HTML, CSS and vanilla JavaScript. It introduces
my background and selected projects, including team work, coursework and
practice projects.

## Run locally

Open `index.html` in a browser. The site does not need a build step or package
installation.

## Project files

- `index.html` contains the page content and structure.
- `styles.css` contains the responsive layout and visual styles.
- `script.js` contains the contact dialog and Banjul local-time clock.
- `mama.jpg`, `gf1.jpg`, `gf2.jpg`, `gf3.jpg`, and `project-*.png` are portfolio
  images.
- `project-*.svg` contains labeled illustrations for the student model and
  Note-Taking API, which do not have a website interface to screenshot.

## Deployment

This static site can be hosted with GitHub Pages from the repository root. In
GitHub, open **Settings → Pages**, select the `main` branch and `/ (root)` as
the publishing source, then save. GitHub will provide the published site URL
after deployment.

The Note-Taking API is linked as a source-code project; it is not deployed as a
live API by this portfolio.
